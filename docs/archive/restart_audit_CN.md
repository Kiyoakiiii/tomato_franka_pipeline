## 环境恢复原则

新增离线盘点工具已实际运行成功：当前 `python3` 为 3.12.3，15 个应用 Python 源文件 AST 语法检查通过。检查未导入这些文件；语法通过不代表导入、依赖或实机运行通过。Python 3.12 与已有 CPython 3.10 扩展存在 ABI 版本差异，不能直接把旧 `.so` 复制到当前解释器使用。

先确认机器人系统版本、FCI、libfranka、franky 实际加载路径、Python ABI、ZED SDK、pyzed、PyTorch 与 CUDA，再选择项目局部环境。旧扩展文件名显示 CPython 3.10 ABI，因此 Python 3.10 是候选起点，不代表此机器已经具备所有兼容依赖。

保持实验室现有系统不变。若需要不同版本，在项目内新建环境和构建目录，不使用旧缓存直接安装。最终记录可复现的版本清单，不保留当前 `requirements.txt` 中只有下限约束的方式作为最终锁定方案。franky 和机器人系统需要对应兼容的 libfranka；参考 [Franka 兼容性入口](https://frankarobotics.github.io/docs/compatibility.html) 与 [franky 官方仓库](https://github.com/TimSchneider42/franky)，不直接升级到最新版。

未来进程的 `PIP_CACHE_DIR`、`XDG_CACHE_HOME`、`TORCH_HOME`、`YOLO_CONFIG_DIR`、`MPLCONFIGDIR` 和临时目录应分别指向本项目 `.cache/`、`.tmp/` 等子目录，且应验证库实际写入位置。只在该进程设置，不修改 shell 启动文件或现有进程。当前没有创建环境或安装包。
