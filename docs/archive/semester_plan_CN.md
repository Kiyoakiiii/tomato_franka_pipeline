# 番茄幼苗移栽八周实施路线

用户已确认剩余约两个月，已有标注数据和训练过的 YOLO，ZED 2i 与夹爪在实验室。本路线以八个工作周安排，具体截止日和设备时段待确定；各周可以部分重叠，最后两周优先保留给正式实验与论文。

建议研究主线是：测出当前夹爪能够容忍多大的定位偏差，再测视觉定位误差，验证两者是否匹配以及是否能完成少损伤移栽。已有模型先复测，只有发现明确的分割瓶颈才补数据或微调。

## 核心范围

固定托盘、固定相机、已知接收杯或孔、可接近且不严重缠绕的幼苗；先使用一个已验证的侧向接近方向和固定运输路径。实现获取、拔出、搬运、释放，并记录拒绝和失败。

“放入接收杯或孔”不包含自动挖穴、覆土、压实或长期存活率验证。人工松根、预先取出、人工选点、人工校正都作为不同实验条件记录，不能混入自主拔出成功率。

优先完成现有 YOLO、RGB-D 局部几何、坐标标定、容差实验和有界状态机。RF-DETR、ROS 2、Isaac Sim、模仿学习、完整植物重建和多款夹爪改型本阶段不排入核心工期。这是针对八周资源的项目选择。

## 技术选择

| 环节 | 本阶段选择 | 具体用途 |
| --- | --- | --- |
| 分割 | 现有 YOLO 权重及原训练版本，必要时小范围微调 | 输出每株可见主茎 mask，优先恢复旧训练配置和测试数据 |
| 图像处理 | OpenCV，必要时 scikit-image | mask 对齐、清理、骨架及分段；细茎不可用强腐蚀一律抹去 |
| 数据采集 | ZED SDK 与匹配的 pyzed | 同一帧左图、XYZ、深度置信图、内参、时间戳和单位 |
| 几何 | NumPy，SciPy | 局部 RANSAC 后 PCA、刚体变换、误差投影 |
| 可视化 | 保存叠图与误差图；需要时用 Open3D | 查看点云污染、直线拟合及抓取坐标系 |
| 机器人 | 经实验室版本验证的 franky 与 libfranka | Python 编排动作；底层执行实时运动和反应 |
| 数据记录 | CSV、JSON、PNG、NPZ | 每次实验可追溯到输入帧、模型、标定、夹爪和结果 |
| 环境 | 项目内局部 Python 环境及缓存 | 复现依赖；不更改共享系统安装 |

本地有 CPython 3.10 扩展，因此先调查兼容的 3.10 环境，不立即安装任何版本。franky/libfranka 与机器人系统的对应关系应按 [Franka 官方兼容性文档](https://frankarobotics.github.io/docs/compatibility.html) 和 [franky 官方说明](https://github.com/TimSchneider42/franky) 核实。

## 八周安排与完成条件

| 周 | 主要工作 | 应产出的证据 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| 1 | 复制并盘点已有数据和训练记录；确认夹爪接口及机器人栈；少量幼苗形态与夹持试验；手工 mask 检查深度 | 数据清单、旧模型离线叠图、茎径与可抓长度记录、深度有效率 | 已知有哪些材料可用；已开始获取夹持和深度的直接证据 |
| 2 | 分开测试搬运与拔出；初测三个方向的偏移容差；固定相机并验证深度重复性 | 成功与损伤记录、初步容差范围、误差和深度缺失例图 | 找到可复现的夹持条件和可靠深度区域，否则调整实验条件与范围 |
| 3 | 同步 RGB-D 数据保存；相机到基座标定与接触中心标定；修复坐标和默认连接问题 | 带版本的变换、独立验证点误差、离线失败用例测试 | 独立误差相对实测容差有余量，且所有不合法目标被拒绝 |
| 4 | mask 连续段、局部三维几何、单方向抓取候选与拒绝规则 | 候选叠图、点云、位置方向误差、拒绝原因统计 | 在留出样本上能稳定选出合格候选；不足时拒绝，不用背景深度补齐 |
| 5 | 状态机及假设备回放；现场空载、假茎、少量真苗联调 | 事件日志、预抓取到放置的完整试运行、失败恢复案例 | 能在规定场景内重复完成流程，失败可归因且能有界退出 |
| 6 | 小批量试验，定位主要失败原因，只做必要修复；冻结配置 | 预试验结果、版本清单、正式实验方案 | 模型、标定、夹爪设置、判定规则固定，原始数据可追溯 |
| 7 | 至少 30 株独立端到端试验；有余量再做一项对照 | 原始计数、阶段成功率、损伤、拒绝、时间和不确定性 | 记录完整，失败和拒绝均纳入预定统计，不临时挑选最好试次 |
| 8 | 分析误差与容差关系、整理失败案例、论文和演示 | 图表、方法、局限、可复现实验包 | 结论由数据支持，区分完全自主与人工辅助条件 |

每周开始检查前一阶段证据；赶工不能通过省略独立标定验证或失败记录来完成。论文中的设备、方法、数据格式和实验设计从第一周同步写。

## 第一周可直接开展的工作

1. 在项目内新建一个数据目录，将原始 RGB、数值深度或 SVO、标注、数据划分、`data.yaml`、旧训练 `args.yaml`、结果曲线和权重一并复制过来，保留原件。文件缺失就标记，不凭文件名补推断。首先区分数值深度与仅供显示的彩色深度图。
2. 按 plant/session 建立数据清单。旧权重若训练过计划中的测试植株，就不能用这些植株报告泛化测试成绩；补采新的植株或时段作为留出集。同株连续帧不能跨训练与测试集合。
3. 在局部兼容环境复测已有模型，先选约 20 张覆盖遮挡、细茎、背景和光照的图片看原图叠加，再统计留出数据。约 20 张只是建议的诊断批量，不是正式性能样本量。
4. 记录夹爪型号、接触垫尺寸、开口与控制接口、可读取的状态、是否支持力限制、安装位置；旧配置里的 15 N 和 8 mm 不作为真苗初始设置。测量实际茎径、叶柄干涉、可抓长度及基质状态。
5. 在安排好的现场时段完成少量已知位置试验：先验证夹持并搬运已取出的苗，再验证从原托盘拔出。假茎用于调试坐标和动作，不能用于替代真苗损伤实验。
6. 相机固定后，用手工选定的主茎小区域测试深度。这样先知道深度本身能否测准，再判断模型是否是限制因素。记录距离、角度、光照、背景、有效点比例、重复波动及对独立参照的偏差。

ZED 数值深度、点云与左图可在同一次 `grab()` 后读取；用于显示的 8 位深度图不能当作数值深度使用。[Stereolabs 深度 API](https://www.stereolabs.com/docs/depth-sensing/using-depth)

## 三维定位与标定的实施细节

建议统一使用米，明确记录相机坐标轴为图像坐标约定 X 向右、Y 向下、Z 向前。ZED 支持显式设置坐标系和单位。[Stereolabs 坐标系说明](https://www.stereolabs.com/docs/positional-tracking/coordinate-frames)

每帧保存：`rgb.png`、含 `xyz_m` 和 `depth_confidence` 的数值文件、时间戳、图像宽高、相机序列号、内参、深度模式、SDK 版本、坐标系、单位和采集 session。XYZ 必须与 mask 所在的原图像素对齐。旧数据只有深度时，须有同一采集配置的内参才能可靠反投影；彩色深度图不能直接恢复原始测量。

处理顺序为：mask 对齐 → 连通与骨架分段 → 提取可靠茎内点 → 排除非有限值和深度跳变 → 每段 RANSAC → PCA 精修 → 输出位置、局部切向、长度、支持点数、有效比例和残差。ZED confidence 值越接近 100 越不可靠，与“检测置信度越高越好”方向相反，过滤阈值需要现场数据确定。[Stereolabs 深度置信图](https://www.stereolabs.com/docs/depth-sensing/confidence-filtering)

拟合残差很小也可能整段拟合到背景或可见表面；独立参照要测轴心或定义清楚的接触中心。细茎没有足够内部像素时，记录为不可测，不强行补出中心线。

令 `T_AB` 表示把 B 坐标变换到 A 坐标。B 为机器人基座，C 为相机，E 为机器人受控末端，G 为夹爪接触中心：

```text
p_B = R_BC p_C + t_BC
tangent_B = R_BC tangent_C
T_BG = T_BC T_CG
T_BE_target = T_BG inverse(T_EG)
```

固定外置相机可从同一个物理标定点在两坐标系的对应坐标求刚体变换。可以用已知工具尖端和可见标记的标定件，需先测清二者的固定偏置；不能把机器人法兰位置当成相机中标记的位置。建议采 12–20 个分布覆盖工作区域和多个高度的对应位置，再留 6–10 个独立位置验证；这些数量是实施起点，不保证精度。不要用同一批拟合点残差冒充定位精度，也不要将平面像素单应性外推到不同高度的茎。

夹爪接触中心偏置随软垫形状及压缩状态可能变化，记录测量方法和有效开口范围。初期保持固定工具接近方向，可减轻姿态验证负担。候选仍必须满足茎方向与闭合轴近似垂直、有效接触长度足够、可达、整条运动路径与机械臂连杆无碰撞。franky 提供运动执行，不替代完整场景规划；第一版使用已验证的有限姿态与路线。

## 用容差决定定位要求

定义三个局部正交方向：闭合方向 c、接近方向 a、沿茎方向 s；在直立苗实验中 s 可近似竖直，但不能混用局部 s 和基座 Z。分别注入正负偏移并记录结果，获得不同方向、不同设置下成功率与损伤随偏差变化的曲线。单方向容差不是三维组合误差容差，之后需要补测组合偏移。

对独立验证目标，将位置误差投影为 `e_c, e_a, e_s`，报告有符号偏差、绝对误差分位数、最大误差及拒绝比例，另报方向角误差。先以固定姿态减少角度变量，后续记录方向误差对长接触区域的影响。

没有测量结果之前，不设“必须 1 mm”之类的统一精度目标。若某方向误差常常超出该方向夹爪可靠区间，依次检查坐标偏置、深度质量、相机摆位、候选拒绝规则、夹垫容差；只有错误来自 mask 时才投入重训练。系统性偏差不能简单用独立随机噪声平方和消掉。

## 状态机的最小行为

```text
观察 → 验证候选 → 预抓取 → 必要时再观察 → 获取 → 拔出 → 运输 → 放置 → 验证释放
                      失败或证据不足 → 停止本次推进 → 根据现场状态决定受控退出或人工处理
```

每个状态记录开始结束时间、输入帧、目标、动作结果和退出原因。明确观察有效期；再观察若遮挡、置信不足或目标改变，需要拒绝或重新规划，不能只刷新图像仍使用旧目标。

动作前检查工作空间、有限值、变换有效性、路径与力学边界；夹持后结合夹爪返回状态及图像判断。夹爪闭合命令返回成功不等于夹住幼苗；仅凭夹爪附近出现绿色也不足以证明带起了目标。

拔出沿预定义方向分段执行，监测可用的外部扳手、位移和目标运动。机械臂外力估计不是茎压缩力；单靠慢速 Python 轮询也不能承担快速接触保护，需确认底层反应机制和设备保护设置。异常接触时不盲目重发动作或自动清错；只有已验证可退路径且设备状态允许才退回。

建议初版每目标最多一次重新观察后重试，次数可经预试验调整并冻结。疑似损伤或拔出阻力异常不重复夹同一株。完整失败分类包括无目标、深度不足、标定无效、不可达、路径受阻、滑落、拔出阻力、释放失败、设备异常。

## 正式评估和调整范围的节点

核心实验为容差测量、独立定位验证及至少 30 株端到端试验。proposal 的 85% 获取、75% 端到端、10% 可见损伤作为目标，不作为承诺；报告原始计数和区间，不只报百分比。具体口径见 [实验记录说明](experiment_protocol_CN.md)。

若做反馈对照，使用不同但匹配的幼苗随机分配至单次观察与再观察组。30 次总量拆成两组只能作为小样本探索；若声称每条件有 30 次，应准备至少 60 株。夹垫对照与反馈对照优先选择一项，避免八周内同时开展。

第二周若发现茎夹持无法在合理损伤下克服拔出阻力，先检查苗龄、含水状态、根团与托盘约束，并和导师明确是否采用标准化预松根或辅助顶出。辅助流程作为独立条件重新命名，不能宣称完成原始条件的自主拔出。

若手工 mask 下深度仍达不到容差，先调整距离、视角、背景与照明，再限定可测场景；不要把平滑背景深度用于机器人。第六周仍无法完成三维自主移栽时，应及时与导师明确论文范围及未完成部分，保留真实的子系统实验结果。
