# 实验记录与统计口径

本说明配合 `experiments/templates/` 中的空白 CSV。表中只有字段，没有虚构试验数据。每次实验将模板复制到项目内以 session 命名的新目录，保留原始图像、视频和日志；修改实验条件时创建新的条件编号。

## 标识与通用填写规则

- `session_id` 对应一次设备安装和采集条件；`plant_id` 对应一株真实幼苗；`trial_id` 对应一次预定试验；`attempt_index` 从 1 开始，同一目标重试仍属于原 trial。
- 长度字段后缀 `_mm` 为毫米，`_m` 为米，时间 `_s` 为秒，力 `_n` 为牛顿，角度 `_deg` 为度。不要在数值列里写单位字符串。
- 布尔结果用 `1` 或 `0`，未知或尚未进入该阶段留空；未发生的阶段不能伪装成已经尝试但失败。
- `condition_id` 对应冻结的条件说明；`setting_id` 对应夹爪命令和实际可控参数，附夹垫、开口、速度、力设置及单位。没有力控制或测量就写 unknown，不将位置命令换算成臆测的夹持力。
- `reference_id` 对应独立测量方法、标定件及其精度或不确定度；`calibration_id` 对应实际使用的变换文件；`model_id` 对应权重和训练记录。相对路径均相对项目根目录。
- 记录原始数据；离线模型重跑不覆盖原记录。缺失值与测量值 0 必须区分。

## 幼苗与实验条件

`seedlings.csv` 每株一行。至少记录苗龄或未知、主茎直径及测量位置、可接近长度、托盘孔位和间距、基质及含水条件、是否预松根、已有损伤。茎径测量尽量避免挤伤，记录工具和分辨率。

各 session 另存条件说明：相机型号与镜头、距离和角度、照明、背景、标定版本、夹垫材料和尺寸、设备软件版本、操作者、环境照片、苗龄与基质管理方式。相机或夹爪安装改变后复核标定。

## 夹持与拔出分开测量

`tolerance_trials.csv` 的 `stage` 使用 `hold_transport` 或 `extract_from_tray`。前者使用已取出且标准化根团重量的苗，检查是否夹稳、运输滑落与损伤；后者保留托盘阻力，检查拔出。两类结果各自统计。

先建立零偏移基线，在能重复夹持的设置上再改变位置。c 是闭合方向、a 是接近方向、s 是沿茎方向；`frame_id` 指向三根轴在基座中的定义。选择侧向接近并保持三方向正交；姿态改变时更新定义。

建议先单轴、正负、由小到大探索。步长依据实测茎径、夹垫及开口确定，不能预设通用毫米容差。试次顺序在可行范围内随机化或按植株批次分块；边界附近增加独立样本。获得单轴曲线后，再补组合偏移验证，不把三个单轴区间简单拼成保证成功的长方体。

记录实际偏移测量值及其来源；如只有指令偏移，也明确标记。已有损伤或经历过拔出的苗不能当作新独立样本。探索阶段重复使用的植株通过 `plant_id` 保留关联，统计时不能把重复帧和重试当作独立试验。

观察夹持后局部压痕、劈裂、折断和弯折，拔出时记录滑移、根团滞留与根系损伤。`peak_external_wrench_n` 仅填写已定义坐标方向和补偿方式下的臂端外力指标，不代表茎压缩力。

容差应表述为特定条件下的成功率曲线及支持样本量，不能用一次成功的最大偏差定义可靠容差。损伤达到现场预定停止条件时终止该条件探索。

## 定位独立验证

`localization_checks.csv` 每个独立参照位置一行；重复拍摄用相同 `reference_id`，不能当作新的参照位置增加样本数。记录估计位置、独立参照位置、局部三轴投影误差、方向误差、有效深度比例和拟合残差。

`reference_role` 使用 `calibration_fit` 或 `held_out_validation`，两类分开分析。独立参照可以来自经测量的标定夹具及已标定工具尖端；只读取机器人位姿不足以得到实际茎轴真值。说明参照自身的误差；固定标记标定通过后，还要验证细茎可见表面到轴心的偏差。

输出每个方向的有符号平均偏差、绝对误差中位数及分位数、最大值、样本数和拒绝数。小样本高分位数不稳定，应附原始散点或误差分布。拟合残差衡量点到拟合线的自洽性，不能替代实际定位误差。

## 端到端试验

`end_to_end_trials.csv` 每株预定目标一行，重试细节写入 `attempts_log_path`。在正式实验之前冻结纳入条件，例如苗龄范围、可见主茎长度、托盘条件和严重缠绕的判断方式，并对每个呈现目标先记录，再让系统决定执行或拒绝。

阶段定义建议如下，预试验后固定：

| 事件 | 判定依据 |
| --- | --- |
| 获取成功 | 夹爪闭合后目标主茎被稳定约束，有夹爪状态或独立视觉证据；无法判断则留空并记证据不足 |
| 拔出成功 | 目标及规定范围的根团从原孔脱离并随夹爪运动，没有滑落；根团完整程度另记 |
| 放置成功 | 目标到达预定义接收位置，完成释放，规定观察时间内保持在接收区域 |
| 端到端成功 | 在预定次数和流程内完成获取、拔出、运输、放置，且无需人工接管 |
| 可见损伤 | 与操作前照片比较出现预定义的新增损伤；分茎损伤和根部损伤记录 |
| 拒绝 | 系统在执行获取前判定不能执行，并给出原因；与操作后失败区分 |

如果无法在拔出前独立验证获取，可将 `acquisition_success` 留空并说明阶段不可分辨；不能把“拔出失败”自动解释为“未夹住”。运输途中落苗另记失败原因。

至少同时报告这些原始计数：呈现目标数、事前不符合纳入条件数、符合条件数、拒绝数、尝试获取数、获取成功数、拔出成功数、完整成功数、人工介入数、可评估损伤数及新增损伤数。

报告获取成功率时写明分母为尝试获取数，并单列获取状态无法评估的数量。完整成功率建议同时给出“符合条件目标”为分母和“已执行目标”为分母；前者保留系统拒绝带来的影响。拔出成功率可报相对尝试拔出的次数，也可报相对已获取目标数，必须给出分母。损伤比例以实际可评估的已操作幼苗为分母，未评估数量单列，不能默认无损伤。另报无损完整成功数。

30 株中达到 proposal 点估计目标对应：至少 26 次获取成功可超过 85%，至少 23 次完整成功可超过 75%，最多 3 株可见损伤为 10%；这些换算仅在相应分母都是 30 时适用。它们不是统计保证。

独立二项试验可用 95% Wilson 区间：令 `p=k/n`、`z=1.96`，中心为 `(p+z²/(2n))/(1+z²/n)`，半宽为 `z sqrt(p(1-p)/n+z²/(4n²))/(1+z²/n)`。`n=0` 时报告无数据。不同批次或同株重复测量存在相关性时，应按批次或植株处理，不能直接按帧计算区间。

周期时间从开始观察到验证释放或终止，包含重试；成功、失败和拒绝的用时分别报告，并另报准备时间。可见损伤在操作前、操作后统一时点拍照；若增加 24 小时复查，各条件保持相同时间窗。没有后续生长试验时，结论限于可见损伤，不声称长期成活率。

## 实验材料目录

建议每个 session 包含条件 JSON、对应 CSV、原始图像或数值深度、叠图、机器人事件日志、前后照片和人工判读说明。记录失败与拒绝原图，避免只保留成功演示。正式实验冻结后如修复算法，应建立新版本并单独报告后续结果。
