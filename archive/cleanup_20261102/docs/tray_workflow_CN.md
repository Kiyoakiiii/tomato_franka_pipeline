# 托盘模式：按穴位夹取 + 视觉修正（当前主线，2026-10-05）

根据与教授讨论后的方向调整：实验重点是实验室新夹爪的效果。流程改为按托盘穴位的已知位置夹取，再放到旁边的杯子里；视觉只负责修正倾斜或偏位的苗，**不需要训练模型**。之前的全图 YOLO 流程（`50_run_transplant.py`）保留为可选方案。

夹爪驱动等新夹爪的接口信息确定后再接入。目前代码里的夹爪仍是 Franka Hand 和仿真夹爪，夹爪抽象层（`seedling/gripper.py`）已经为新增类型预留了位置。

## 流程

```
示教托盘：3 个角穴位 → 自动插值出所有穴位            scripts/45_teach_tray.py
      ↓
按“靠近接近方向的一侧先夹”的顺序逐个穴位：         scripts/55_run_tray.py
  [vision 模式] 拍照 → 本穴位的视觉修正 → 修正后的抓取点和茎方向
  [blind 模式]  直接用示教位置，假设茎直立
  → 预抓取 → 接近 → 夹取 → 分段拔出（力阈值） → 运输 → 放入杯子 → 松开 → 拔出后拍照检查原穴位
```

- **示教**：在 A（第一行第一列）、B（第一行最后一列）、C（最后一行第一列）三个穴位上，把夹爪中心点动到直立苗的茎上、基质以上的抓取高度。托盘可以斜着放，其余穴位按行、列向量插值。脚本会检查行列是否垂直、穴距是否与标称值一致。
- **夹取顺序**：按接近方向排序，先夹离机械臂近的那一排。这样手指伸进去时不会扫到还没拔的相邻苗。如果相机也从机械臂这一侧看过去，前排先被移走，后排也会慢慢露出来。
- **接近方向**：托盘模式只用"基座指向穴位"的方向（偏航 0°），向下倾角先试 45°，不可达再试 60°，可在 `tray.approach_*` 里修改。整套动作（预抓取、抓取、拔出、运输、放置）的 IK 检查结果：抓取点高度 8 cm、y 在 ±7.5 cm 范围内时，45°/60° 在 x = 0.40–0.60 m 全部可达；30° 只有 x ≥ 0.55 m 才可达，因为手要更"平"地伸向靠近基座的低处，FR3 关节会到极限。**建议把托盘放在距基座 0.45–0.60 m 处。**

## 不训练模型的逐穴位视觉修正（`seedling/tray.py`）

1. **取点区域**：只取本穴位上方的点。范围是一个锥形：基质表面以上 0.8–6 cm 高度内，底部半径 2 cm，向上按最大倾角张开。茎下段基本只在这个范围里，高处的叶片和基质都被排除。
2. **基质高度**：用穴位中心附近最低的一层密集点修正示教时的基质高度。
3. **绿色过滤**：用归一化色度的 ExG = 2g − r − b 设阈值，把绿色的茎和褐/黑色基质、黑色托盘、白色珍珠岩分开。
4. **直线拟合**：用顺序 RANSAC 找出多条直线（邻苗可能倾斜伸进来），只接受与基质交点落在本穴位中心 2 cm 内的那条，即扎根在本穴位的茎。然后求它在抓取高度处的位置和倾斜方向。
5. **退化处理**：
   - 点的高度跨度不够时，只估位置、不估倾斜。
   - 点太少、修正量超过 3 cm、或倾角超过 40° 时判为失败。失败后按 `tray.vision.fallback` 处理：`nominal` 退回示教位置，`reject` 跳过该穴位。
   - 所有处理结果都会记录下来。
6. **拔出后检查**：再拍一次，看本穴位是否还有扎根的茎。这个检查在 blind 模式下也做，前提是有相机标定。

阈值都在 `configs/pipeline.yaml` 的 `tray.vision` 里，ExG 阈值要按现场光照调。拿到实际的苗后，用 `scripts/10_capture.py` 拍几张看看效果。

## 仿真结果（合成托盘 3×4、穴距 50 mm、抓取高度 35 mm、相机标定完美）

单穴位视觉定位精度，每个倾角 48 个穴位：

| 倾角 | 按示教位置的偏差（中位） | 视觉修正后误差（中位 / 90%） | 视觉成功 |
| --- | --- | --- | --- |
| 0° | 1.5 mm | 0.3 / 0.6 mm | 46/48 |
| 15° | 9.6 mm | 0.5 / 0.7 mm | 46/48 |
| 30° | 20.4 mm | 0.8 / 1.2 mm | 45/48 |

失败的穴位基本是后排被前排叶子挡住的情况。

端到端对比（`55_run_tray.py --sim --study 0,10,20,30,40`，每个倾角、每种模式 12 个穴位）。结果在 `experiments/tray_runs/20261005_122110_sim_study/`，含 `study.png`：

| 倾角 | blind（按示教位置） | vision（逐穴位修正） |
| --- | --- | --- |
| 0° | 12/12 | 12/12 |
| 10° | 12/12 | 12/12 |
| 20° | 10/12 | 12/12 |
| 30° | 5/12 | 12/12 |
| 40° | 2/12 | 6/12 |

- blind 的失败全部是"夹空"。抓取高度 35 mm 时，20° 倾斜偏 13 mm，30° 偏 20 mm，开始超出仿真夹爪的容差。
- 40° 时 vision 也只成功一半。原因有两个：一是倾角刚好碰到 `tray.vision.max_tilt_deg = 40` 的上限，直线拟合被拒，退化成"只估位置、按直立处理"；二是茎倒向接近方向时，固定接近方向几乎和茎平行，一个穴位因此被拒。改进方法是按茎的倾斜方向选择接近方向，目前未实现。
- 拐点出现在哪个倾角，完全取决于夹爪的容差。仿真里用的是几何占位值，真实的拐点要用实验 A 测出的新夹爪容差来确定。

**这些数字只说明软件和方法在理想条件下是对的**：
- 仿真里的夹爪用几何规则判断夹住与否：茎落在两垫之间，沿闭合方向 ±15 mm、沿接近方向 −20~+10 mm 内算夹住。这不是新夹爪真实的容差。
- 相机深度是理想圆柱加轻噪声，比真实 ZED 在细茎上的深度好得多。

真实效果取决于两件事：新夹爪的实测容差，以及 ZED 在实际苗茎上能拿到多少有效深度。

## 实验室使用

```bash
P=.venvs/pipeline/bin/python
# 1. 示教托盘（先用 21_robot_jog.py 把夹爪移到 A1 附近，夹爪保持抓取姿态）
$P scripts/45_teach_tray.py --rows 4 --cols 6 --grasp-height-mm 30 --expected-pitch-mm 50
# 2. 不用视觉，先夹假茎/直立苗，每个动作前确认
$P scripts/55_run_tray.py --cells A1,A2 --mode blind --step --ask --pause
# 3. 视觉修正（需要手眼标定 calibration/T_base_cam.yaml）
$P scripts/55_run_tray.py --cells A1,A2 --mode vision --step --ask --pause
# 4. 对比实验：同一盘内随机平衡分配 blind/vision
$P scripts/55_run_tray.py --mode alternate --ask --pause
```

每次运行输出到 `experiments/tray_runs/<时间>_.../`：
- `end_to_end_trials.csv`：与实验模板同列，`condition_id` 为 `tray_blind` 或 `tray_vision`。
- `tray_trials.csv`：每个穴位一行，包括使用的是视觉还是示教位置、估计的倾角和修正量。仿真时还有真值。
- 每个 trial 的事件日志和穴位叠加图（`*_cell.jpg`：蓝色十字为示教位置，绿色十字为视觉估计位置，黄框为取点区域）。

## 对应的实验设计建议

| 实验 | 内容 | 回答的问题 |
| --- | --- | --- |
| A. 夹爪表征 | `40_tolerance_trial.py`：已知位置下测 c/a/s 三个方向的偏移容差，夹持搬运与拔出分开测 | 新夹爪的能力边界（实验室最关心的） |
| B. 不用视觉夹直立苗 | `55_run_tray.py --mode blind` | 基础流程成功率、损伤、周期 |
| C. 不用视觉 vs 视觉修正 | 不同倾角的苗，`--mode alternate` | 视觉在什么倾角下开始有用，能把可夹倾角范围扩大多少 |

倾斜程度可以取自然倾斜的苗（先用视觉或量角器记录倾角），也可以人为把苗按固定角度插斜。

关键的连接点：在抓取高度 h 处，倾角 θ 造成的偏移约为 h·tanθ。拿实验 A 测出的容差就能预测不用视觉在多大倾角下会开始失败，再用实验 C 验证这个预测。
